## 这是什么产品？

听现 Lishon 是 MAIS·AI Studio 打造的 Windows 桌面翻译应用，将划词翻译、屏幕字幕、实时听译和个人语库放在同一个工作流程中。

阅读外文资料时，选中文字查看对照；观看外语视频时，识别字幕或声音；遇到有用的表达，保存为单词、句子卡片。开启历史记录后，还能把一段听译或屏幕翻译留在本地，稍后阅读、整理和导出。

它适合外文阅读、课程学习、视频研究，以及需要反复核对原文的工作场景。产品希望减少复制、切换窗口和重复查词，让翻译结果可以继续用于学习。

## 核心功能

| 功能 | 可以完成什么 |
| --- | --- |
| **划词翻译** | 自动读取支持应用中的选中文字，也可粘贴或手动输入。原文更新后自动翻译，清空原文时同步清空译文；支持语言互换、原文与译文独立字号。 |
| **屏幕字幕** | 框选画面中的文字区域，持续识别并翻译。支持重新选框、调整四角，以及暂停、继续、停止。暂停保留区域和当前字幕。 |
| **实时听译** | 识别系统声音或麦克风，将译文显示为桌面字幕；支持导入录音、音视频文件，并导出 SRT 字幕。 |
| **我的语库** | 保存喜欢的单词、单词卡片、句子卡片；支持搜索、语种筛选、排序、多语言对照和批量删除。新增本地翻译历史与独立阅读面板。 |

## 新版重点：翻译结束，内容还能继续用

### 自动保存本地翻译历史

在 **设置 → 处理与隐私** 开启“保存本地翻译历史”，并选择保存文件夹。也可从 **我的语库 → 本地翻译历史** 完成设置。

屏幕字幕或实时听译会话超过 **15 秒有效运行时间**后，原文和各语种译文会保存为本地记录，暂停时间不计入。AI 与本地模型生成的结果都可以记录；关闭保存功能不会删除旧记录。

历史列表支持滚动查看。双击名称可改名，双击内容预览可阅读；也可定位文件、删除单条或批量删除。删除记录会同时删除其对应的本地文件。

### 在侧边阅读，也能独立摆放

双击历史记录，在主窗口右侧打开同主题的阅读面板。面板显示记录标题，重命名后同步更新。

- **逐条对照**：每条原文后跟随相应的译文，便于核对表达。
- **按语种归类**：原文和不同语种译文分别组成段落，便于连续阅读；显示编号时，同一条内容在不同语种中保持对应编号。
- **自由移动与吸附**：拖开后可独立摆放，靠近主窗口右边缘并松手即可重新吸附。
- **全屏阅读**：保留当前排列方式，文字集中在屏幕中间，两侧留白。

本次更新修复了阅读面板在窗口移动时累积膨胀的问题，并调整了跟随、脱离和吸附逻辑。

### 按当前视图导出笔记

阅读面板右上角提供 **排列方式、序号与语种提示、导出、全屏、关闭**五个按钮。

导出支持 **Markdown / PDF**，使用当前排列方式。关闭“显示序号和语种”后，阅读面板与导出文件都会省略这些提示，保留正文；导出按钮完成操作后仍保持原图标。

PDF 使用白底、黑色正文和中灰色语种标注。Markdown 的灰色语种标注使用内嵌 HTML 样式，具体效果取决于阅读器是否支持。旧版 Markdown 历史仍可读取。

## 按自己的习惯显示字幕

字幕支持拖动位置、居中显示、自动换行，以及原文与译文显示切换。宽度提供 **20 档**，设置范围最高 **3840 逻辑像素**；实际屏幕占用与 Windows 缩放有关。还可调整最近 **1–3 组**字幕内容的显示。

在设置中选择字体、字号、文字颜色、文字投影，以及背景颜色、不透明度和磨砂效果。背景可关闭，颜色选择使用固定配色圆点。最多设置 **3 种目标语言**，分别调整顺序、字号和颜色。

应用提供亮色、暗色两种主题，支持中文、英语、日语、韩语、法语和俄语界面。界面语言与翻译语言独立设置。

![播放视频时的多语种桌面字幕](docs/images/readme/desktop-multilingual-captions.png)

## 本地翻译与 AI，随时切换

顶部胶囊开关可在 **本地翻译 / AI 翻译**之间切换，关闭 AI 不会删除已保存的 API 配置。

完整安装包内置英语与中文、日语、韩语、法语、德语、西班牙语、俄语的双向翻译模型，共 **8 种语言、14 个直译方向**，以及 **Whisper Base** 语音识别模型。这些已支持的本地能力安装后可离线使用，无需另外下载内置模型。

其他缺少本地直译模型的语言组合可使用 AI，软件不会默认经英语中转。

进入“接入 AI”，选择服务商并填写自己的 API Key、服务地址和可用模型。预设包括 DeepSeek、通义千问、Kimi、OpenAI、Gemini、Claude，也支持自定义兼容接口。

内置翻译 Agent 根据原文及可选短上下文处理固定短语、混合语种和专业表达。可选择实时优先或增加复核的精校优先；后者会增加等待与 API 用量。实际质量仍取决于识别结果和所选模型。

## 从第一次使用开始

1. **安装**：运行完整安装 EXE，分别选择软件和模型目录；两者可以相同，也可放在不同目录或磁盘。
2. **选模式**：无需 API 时使用本地翻译；需要 AI 时先填写并保存连接配置。
3. **选语言**：设置识别语言与目标语言，然后进入划词、屏幕字幕或实时听译。
4. **留住内容**：收藏单词与句子，或开启本地历史记录，结束后阅读和导出。

音频设置中的 **2–8 秒**表示每次先收集多长的声音：短一些更快响应，长一些保留更多上下文。实际等待还包括识别、翻译及可能的网络耗时。

收藏词可在实时翻译中高亮，颜色可调整。实时高亮最多索引 **2,000 条记录**，关闭后可继续保存，关键词搜索仍然可用。

## 安装、数据与使用范围

- **系统**：Windows 10 2004 及以上或 Windows 11，x64。
- **安装包**：约 2.06 GiB，主要体积来自内置模型。软件和模型位置均可自定义；具体步骤见[安装说明](安装说明.md)。
- **存储**：历史记录保存在所选文件夹的 `Lishon-History` 子目录。修改存储位置不会自动搬迁旧记录。
- **卸载**：可分别选择是否删除历史记录与安装器登记的模型；默认不勾选，保留资料。
- **数据处理**：本地模式在设备上识别与翻译；AI 模式会向所选服务商发送待译文字及开启的短上下文，API 费用由服务商决定。
- **适用范围**：跨应用划词依赖应用支持和权限；部分屏幕识别语言需要 Windows OCR 语言功能。声音、画面质量和硬件性能会影响效果，不承诺零延迟或完全准确。
